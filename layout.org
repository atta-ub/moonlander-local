#+TITLE: Moonlander layout overview
#+DATE: 2026-10-28

Keep this in sync with =keymap.c=. =✗= = disabled key (=KC_NO=).
Same layers as the Voyager (=../voyager-local/layout.org=); the extra
Moonlander keys are off on every layer: the 3-key inner columns (=xtra=),
the 5-key bottom row, the red thumb keys and the innermost thumb keys.

Meta (xmonad mod) is in three places: hold G, hold M, or hold Enter.
Lock (top left, every layer, 2026-11-06) = Layer Lock: hold a layer key, tap
Lock to keep that layer on, tap Lock again to go back; it glows white while
locked. Holding it while plugging in still starts flash mode (bootmagic).
Macro (top right) = macro 1; on layer 2, M1 (J position) = macro 1 and
M2 (L position) = macro 2 (2026-11-07). Hold ~quarter second = start recording
(key turns red), type, tap any macro key = stop; then tap = play it back.
Both macros share ~128 keystrokes and are lost when unplugged. Layer-key holds
and Lock are never recorded. Caps Word moved to both Shifts (hold R + I).

Media keys need the xmonad bindings in =dotfiles/desktop/wm/xmonad.org=.
Th1-Th5 = LED themes, LEDs = all lights on/off, Brght/Dim = brightness
toggles (see LEDs below).

* LEDs (same as the Voyager)
- One colour per layer, set by the theme; theme 1: 0 green, 1 violet, 2 blue
  (brightness 150; highlights 230-255). Colours below are theme 1's.
- Themes: hold Space, then the top row picks one (kept after unplugging);
  each theme key glows in its theme's base colour.
  | Key | Theme         | Base    | Mods  | Layer 1 | Layer 2       |
  |-----+---------------+---------+-------+---------+---------------|
  | 1   | Green + coral | green   | coral | violet  | blue          |
  | 2   | Teal + coral  | teal    | coral | pink    | deep blue     |
  | 3   | Las Vegas     | purple  | gold  | hot pink| electric blue |
  | 4   | Classic       | blue    | amber | indigo  | green         |
  | 5   | Dark (ef)     | dim     | coral | dim     | dim           |
  Key 6 turns all LEDs on/off (=RM_TOGG=); unplugging turns them back on.
  Key 7 = Bright toggle: every colour below 200 is raised to 200 (=BRIGHT_VAL=);
  brighter ones, like the mods, stay. Key 8 = Dim toggle: everything at 35%
  (=DIM_PERCENT=). One turns the other off; the active key glows white;
  the mode is kept after unplugging, with the theme.
  Colours: the =themes= table in =keymap.c=.
- Keys that are a modifier on hold on the base layer (R S T G, M N E I,
  Enter / Meta) are coral on the base layer. The firmware finds every =MT(...)=
  key in layer 0 at start-up, so a moved mod moves its colour.
- A mod key turns white while you hold it and its modifier is really on
  (every layer), so a hold that became Shift/Ctrl/Alt/Meta is easy to see.
- Layers 1 and 2 colour keys by group: numbers yellow, arrows white,
  Home/End/PgUp/PgDn white, F-keys yellow, media pink; symbols keep the
  layer colour. These win over coral, which is why coral is base-layer only.
- Caps Word (hold R + I together ~250 ms and let go): the letter keys are
  magenta
  on the base layer until Caps Word ends.
- Keys that are =KC_NO= on the current layer are off (always: inner columns,
  bottom row, red and innermost thumb keys), so a held layer shows
  only its working keys. For a dim colour, change =LED_UNUSED= in =kind_colors=.
- QK_BOOT (layer 2, top right) is red.
- Macro keys (base top right, layer 2 M1/M2) are red while their macro records.
- The layer-tap thumb keys show the colour of the layer they open, brighter,
  on the base layer: Space blue (layer 2), Repeat and Backspace violet (layer 1).
- All LEDs turn off after 5 minutes without a key press; the next key turns
  them back on and still types (=RGB_MATRIX_TIMEOUT= in =config.h=).

* Timing (same as the Voyager)
- Home row mods: 200 ms hold, 250 ms on R I (ring).
- Chordal hold: a same-hand key while holding = tap; outer columns and all
  thumb keys are exempt (T + Backspace thumb = Ctrl+Backspace).
- Flow tap: a home row key within 150 ms of a letter or Space = tap.
- Space: time only (no permissive hold), like kanata's Space layer on the laptop.
- Enter / Meta: 200 ms hold, permissive hold, no flow tap, so Meta works
  right after typing.
